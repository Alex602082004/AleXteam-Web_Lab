# AleXteam-Web_Lab

## Overview
This repository contains a web application developed for the Web Programming course. It is a PHP-based project that demonstrates foundational web development concepts, including user authentication, form handling, and database interactions.

## Features
* **User Authentication:** Secure login and logout functionality (`LogIn.php`, `Logout.php`).
* **CRUD Operations:** Complete Create, Read, Update, and Delete capabilities for managing database entries (`Add.php`, `Home.php`, `Edit.php`, `Delete.php`).
* **Database Integration:** Centralized database connection and management (`db.php`).
* **Form Processing:** Interactive HTML forms with PHP backend validation and processing (`Formulare.php`, `Formulare.html`).

## Technologies Used
* **Backend:** PHP
* **Frontend:** HTML, CSS
* **Database:** MySQL
